# Brief — public-promotion-kernel-foundation-v1

**Status:** FOUNDATION COMPLETE when the initial public commit, tests, and repository settings are verified.

## Objective

Establish a public, independently versioned repository for a simplified, model-independent promotion kernel without copying the current governed controller or any Shedu product code, private governance corpus, credentials, run evidence, or provider configuration.

## Product boundary

The kernel owns only exact work binding, isolated execution, immutable candidate identity, deterministic validation, independent outcome review, and signed disposition. Exploration, authoring, recursive learning, benchmarking, dashboards, organization administration, product policy, and target application code are external systems connected through explicit contracts.

## Foundation requirements

- Public GitHub repository with Apache-2.0 licensing and private vulnerability reporting enabled.
- Honest `FOUNDATION_ONLY` status; no production-readiness or certification claim.
- Dependency-free machine subject probe with a failing closed non-probe path.
- Exact argument arrays in the Harness Bench subject contract.
- Automated tests proving probe identity and fail-closed behavior.
- No copied controller implementation, secrets, generated evidence, or product artifacts.

## Harness Bench relationship

Harness Bench treats `shedu-governance-harness` as the exact baseline subject and this repository as a distinct exact candidate subject. Each is resolved independently to an immutable commit SHA and materialized in its own disposable environment. Bench may compare them, emit findings, and generate candidate patches, but cannot promote either subject.

## Next governed implementation

Implementation begins with the six-stage promotion path documented in the README. Each stage must have a typed input/output contract, deterministic negative controls, an append-only event record, and a mechanically verified ownership path before it is admitted. The first implementation slice must not import or transplant the legacy controller wholesale.
